# RuyiSBI

RuyiSBI is an early-stage research project exploring the RISC-V Supervisor
Binary Interface (SBI). Its research question and technical approach are still
being developed.

## Current status

- The research direction is open.
- A prototype has not been implemented.
- Experiments and results have not been added.

## Explore the project

The [research](research.md), [prototype](prototype.md), and
[experiments](experiments.md) pages describe the current state of each part.
The project source is available on [GitHub](https://github.com/Plucky923/RuyiSBI).
