# RuyiSBI

RuyiSBI is an early-stage research project. Its research question, design,
and evaluation plan are still being explored.

## Repository layout

- [`docs/`](docs/README.md): research notes and design documentation.
- [`prototype/`](prototype/README.md): the future experimental implementation.
- [`experiments/`](experiments/README.md): experiment descriptions, scripts,
  and results as they are developed.

## Current status

There is no implementation or runnable experiment yet. Build and evaluation
instructions will be added when those parts of the project exist.
